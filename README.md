# Nyx Solutions x Arvo.

## Escopo:

**Descrição:**
Arvo é uma healthtech brasileira focada em soluções B2B para otimizar os processos da área de saúde. 
Com o alto volume de dados de internações e procedimentos médicos a empresa oferece uma solução SaaS que atua como uma validação e automatização de auditórias para operadoras de plano de saúde.
O diferencial da empresa é a capacidade de processar contas hospitalares em larga escala, aplicando a tecnologia em uma etapa analítica e burocrática que aponta inconsistências nas faturas, caso pertinente.

## Sobre o projeto
Nosso cliente atualmente tem um gargalo de custos com participações em eventos nacionais e internacionais, visando novas referências, consolidação de conhecimento e ampliação de networking. Sua solicitação foi de um mapeamento dos próximos eventos, para selecionar racionalmente em quais a participação será mais recompensadora. 
Planejamos fazer uma análise automatizada, com todas as convenções que aconteceram naquele ano, com uma descrição detalhada já informando se compensa a participação e todos os seus gastos.
