# Nyx Solutions x Arvo.

## Escopo:

**Descrição:**
Arvo é uma healthtech brasileira focada em soluções B2B para otimizar os processos da área de saúde. 
Com o alto volume de dados de internações e procedimentos médicos a empresa oferece uma solução SaaS que atua como uma validação e automatização de auditórias para operadoras de plano de saúde.
O diferencial da empresa é a capacidade de processar contas hospitalares em larga escala, aplicando a tecnologia em uma etapa analítica e burocrática que aponta inconsistências nas faturas, caso pertinente.
