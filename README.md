A **Arvo** é uma healthtech brasileira focada em soluções B2B para otimizar os processos da área de saúde.

Com o alto volume de dados provenientes de internações e procedimentos médicos, a empresa oferece uma solução **SaaS** voltada para a validação e automação de auditorias realizadas por operadoras de planos de saúde.

O diferencial da empresa está na capacidade de processar contas hospitalares em larga escala, utilizando tecnologia analítica para identificar inconsistências nas faturas, quando pertinente.

## Sobre o projeto

Atualmente, nosso cliente possui um gargalo relacionado aos custos de participação em **eventos nacionais e internacionais**.

A participação nesses eventos tem como objetivos:

- Buscar novas referências;
- Consolidar conhecimento;
- Ampliar o networking;
- Avaliar a relevância dos eventos para a empresa.

Diante desse cenário, foi solicitada a realização de um **mapeamento dos próximos eventos**, permitindo analisar de forma estruturada quais participações podem ser mais recompensadoras para o cliente.

O projeto propõe uma análise automatizada das convenções que aconteceram ou acontecerão naquele ano, apresentando uma descrição detalhada de cada evento e indicando as informações necessárias para avaliar a participação e seus respectivos gastos.

---

## Objetivos

O projeto tem como principais objetivos:

- Mapear os próximos eventos nacionais e internacionais;
- Reunir informações relevantes sobre as convenções analisadas;
- Automatizar o processo de análise dos eventos;
- Apresentar uma descrição detalhada das convenções;
- Auxiliar na avaliação da participação em cada evento;
- Considerar os gastos relacionados à participação;
- Facilitar a análise dos eventos para apoiar o processo de decisão do cliente;
- Contribuir para uma utilização mais estruturada dos recursos destinados à participação em eventos.

---

## Escopo do Projeto

O projeto contempla o levantamento e a análise dos eventos considerados relevantes para o cliente.

O processo pode ser organizado nas seguintes etapas:

### 1. Levantamento dos eventos

- Identificação dos próximos eventos;
- Reunião das informações disponíveis sobre cada convenção;
- Organização dos eventos para posterior análise.

### 2. Análise das convenções

Para cada evento, será realizada uma análise das informações levantadas, buscando apresentar uma visão detalhada da convenção.

A análise considera a necessidade de avaliar:

- Relevância do evento;
- Possível contribuição para novas referências;
- Possibilidade de consolidação de conhecimento;
- Potencial de ampliação do networking;
- Gastos relacionados à participação.

### 3. Análise automatizada

O projeto busca automatizar a análise das convenções, permitindo organizar as informações de maneira estruturada.

A automação tem como finalidade facilitar a comparação das informações levantadas e tornar o processo de análise mais organizado.

### 4. Avaliação da participação

Após o levantamento e a análise das informações, os dados serão utilizados para avaliar se a participação em cada evento compensa considerando os seus respectivos gastos.

## Informações analisadas

A análise dos eventos deverá apresentar uma descrição detalhada das convenções consideradas no levantamento.

Entre as informações relevantes para a análise estão:

- Identificação do evento;
- Informações sobre a convenção;
- Contexto do evento;
- Relevância para o objetivo do cliente;
- Possibilidade de obtenção de novas referências;
- Possibilidade de consolidação de conhecimento;
- Possibilidade de ampliação de networking;
- Gastos relacionados à participação;
- Avaliação da compensação da participação.

## Fluxo do Projeto

O fluxo geral do projeto pode ser representado da seguinte maneira:

1. **Mapeamento dos eventos**
   - Levantamento das próximas convenções.

2. **Organização das informações**
   - Reunião e estruturação dos dados encontrados.

3. **Análise automatizada**
   - Processamento das informações dos eventos.

4. **Descrição dos eventos**
   - Apresentação detalhada das convenções analisadas.

5. **Análise de participação**
   - Avaliação dos benefícios e dos gastos relacionados.

6. **Resultado da análise**
   - Informações organizadas para auxiliar o cliente na avaliação dos eventos.

---

## Critérios de análise

A análise será estruturada considerando os objetivos apresentados pelo cliente.

Os principais pontos considerados são:

- **Referências:** possibilidade de encontrar novas referências;
- **Conhecimento:** contribuição para consolidação de conhecimento;
- **Networking:** possibilidade de ampliar a rede de contatos;
- **Custos:** gastos necessários para participação;
- **Compensação:** análise da relação entre a participação e seus respectivos gastos.

---

## Resultado Esperado

Ao final do processo, espera-se obter um **mapeamento estruturado dos eventos**, acompanhado de uma descrição detalhada das convenções analisadas.

A organização dessas informações permitirá que os eventos sejam avaliados considerando seus objetivos e os gastos envolvidos na participação.

Dessa forma, o projeto busca facilitar a análise das próximas convenções e fornecer ao cliente informações organizadas para avaliar em quais eventos sua participação pode ser considerada.
